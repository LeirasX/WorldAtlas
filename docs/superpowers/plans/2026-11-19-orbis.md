# ORBIS implementation plan

Goal: deliver a functioning map-centered ORBIS increment while retaining existing data tools.

Architecture: reuse React, the offline D3 map, shared country observations, entity index and validated content packs. Keep the repository name, native identifier, storage keys, source archives and public permissions stable.

1. Repair Pages artifact consistency; verify deployed build.
2. Rebrand visible web/native identity; preserve URLs and existing routes.
3. Add Explore map home with eight data-driven lenses and contextual country panel. Reuse map controls, actual metric availability and source metadata. Unsupported lenses explain content gaps rather than drawing fabricated layers.
4. Reduce primary navigation to Explore, Topics, Compare. Keep country directory, complete tables, legacy map and comparison tools accessible.
5. Extend portable entity/article models with content status, sections, source associations and relationship evidence. Expose populated indicator entities through search and existing evidence views.
6. Verify public/local unit and browser workflows, phone layout, offline map, production builds and macOS packaging. Commit/push each ready increment and verify Pages.

Later content increments: independently sourced introductory articles across all domains, occupation observations, legal jurisdiction records, timelines and city coordinates. Do not present these as populated capabilities.
